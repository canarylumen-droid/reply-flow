# ReplyFlow

## Overview
ReplyFlow is a React-based web application built with Vite and Tailwind CSS. It features animations using Framer Motion and toast notifications.

## Project Structure
- `/src` - Main source code
  - `/components` - React components
  - `/assets` - Static assets
  - `App.jsx` - Main application component
  - `main.jsx` - Entry point
  - `index.css` - Global styles
- `/public` - Public static files
- `index.html` - HTML template
- `vite.config.js` - Vite configuration
- `eslint.config.js` - ESLint configuration

## Tech Stack
- React 19
- Vite 7
- Tailwind CSS 4
- Framer Motion
- React Hot Toast

## Development
Run with `npm run dev` - serves on port 5000

## Build
Run with `npm run build` - outputs to `/dist`

## Deployment
Configured for static deployment with the built `/dist` directory.
